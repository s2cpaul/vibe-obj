## Global Gen-AI Community Web UI

A modern, elegant web user interface for hosting a Global Gen-AI Community platform with persistent web applications.

### Features
- **Homepage** (`index.html`): Mission statement, About Us, Services, and Persistent Web Applications showcase
- **FAQ Page** (`faq.html`): Comprehensive frequently asked questions organized by category
- **Responsive Design**: Mobile-friendly layout with modern styling
- **Clean UI**: Gradient color scheme, smooth animations, and intuitive navigation

### How to View
Simply open `index.html` in your web browser, or run a local server:

```bash
python3 -m http.server 8080
```

Then navigate to `http://localhost:8080/index.html`

### Pages
- **Home**: Overview of the platform's mission, services, and available applications
- **FAQ**: Detailed answers to common questions about the platform
